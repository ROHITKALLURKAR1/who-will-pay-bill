# Who Will Pay The Bill? 🎉

A simple Java Swing application that randomly selects who will pay the bill.

## Features
- Add multiple names
- Randomly pick one person
- Simple GUI using Java Swing

## Technologies Used
- Java
- Java Swing
- ArrayList
- Random Class
